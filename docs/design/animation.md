# 角色动作与纸娃娃动画策划

## 目标

玩家通过身体动作读懂“谁做了什么、对谁产生影响”。同一角色跨房间、换装、
站坐及行动时保持相同的头、身体比例和关节。动作由实际游戏结果触发，
暂停模拟时玩家仍可移动和查看动作。美术采用明亮横向卷轴风格。

## 动作目录

| 动作 | 视觉设计 | 播放方式 |
|---|---|---|
| 待机 | 轻微呼吸，脚底不漂移 | 循环 |
| 行走 | 左右交替支撑、摆臂、抬脚；步频与移动速度一致 | 移动期间循环 |
| 坐下／站起 | 髋、膝和手臂连续过渡；坐下后维持坐姿 | 约 350ms，随后保持目标姿态 |
| 上下楼梯 | 按连接器方向迈步，身体沿楼梯路径移动 | 按路径长度播放 |
| 爬梯 | 左右手脚交替抓踏梯级，沿梯子移动 | 按路径长度播放 |
| 观察／阅读 | 头和上身朝向线索，短暂停留 | 约 700ms |
| 操作物件 | 伸手、接触、收回，表达按键、敲击和终端操作 | 约 650ms |
| 交谈／指示 | 面向对象，手臂作一次明确示意 | 约 800ms |
| 喂食／递交 | 伸手递出，接受者以进食或接收动作响应 | 约 800ms |
| 进食／饮用 | 身体靠近食物，头和手部共同完成动作 | 约 900ms |
| 劳动 | 躯干、手臂重复施力，脚保持支撑 | 一次行动约 1000ms |
| 正反馈 | 短暂舒展、点头或抬手，然后回到原姿态 | 约 650ms |
| 负反馈／受惊 | 回缩、后倾、恢复，避免全身随机抖动 | 约 500ms |

转身由行动方向决定。换装仅替换部件，不重启动作、不改变骨架或世界状态。
瞬移、梦境层切换和读档直接落到新场景，不播放穿墙行走。

## 角色适配

人形采用同一关节模型。服装贴图绑定躯干、上臂、前臂、大腿与小腿；
头部随上身姿势移动。动作采样只产生关节位置和角度，服装不含动作逻辑。

狗、猫和雏鹅使用各自的身体表现，接收同一套行走、姿态和交互语义。
四足角色行走采用已有正式步态帧；进食低头、按钮操作抬爪、受惊回缩，
坐起以锚定地面的过渡连接已有站／坐素材。雏鹅以迈步、啄食和转头表达。
主脑以整体呼吸、伸缩、受击收缩和指令脉冲表达行动，不套用人的坐姿或摆臂。

当前不为每个人物生成一套独立整身动作图。现有纸娃娃部件、动物步态帧和
静态正式素材共用动作时间轴；需要新部件时补充部件，不复制整套人物。

## 动作触发契约

Rust 继续负责世界坐标、站坐姿态、命令成败、物品与需求结果。
动画是前端短期表现状态，不进入存档，也不改变通关判据。

每个角色保留一个当前视觉动作：动作标识、起始时刻、时长、起止位置和
需要的目标信息。移动更新当前行动的目标；新行动接续当前画面位置。
站坐变化连续过渡；成功穿越连接器时显式传递 stairs／ladder 类型及端点。
房间切换或载入新世界清除旧动作。

指令动作只消费此次返回的成功事件，不遍历累计日志反复播放。
自主行动依据实际执行事件和对应动作节点触发。已排队但未执行的命令不演出，
被拒绝的命令不演出成功动作。没有身体行为的认知编辑仅播放相应反应，
不虚构位移、物品转移或成功结果。

使用固定的语义动作表覆盖当前关卡命令，名称以命令 ID／动作 schema 为键，
不依据翻译后的中文或英文猜动作。重复调用和帧更新使用同一播放器，
删除原来分散的行走定时器、坐姿瞬切和坐标变化猜动作逻辑。

## 中断与可访问性

玩家再次移动时，动作从当前画面姿态接续。场景跳转立即切换场景，不让旧动作
在新房间继续。角色被移除时销毁播放器。减少动态效果模式保留最终姿态、
行动朝向和文字结果，跳过连续摆动与位移插值。

镜头移动只改变投影，不重置角色动作。地面锚点、楼梯踏面与梯级位置作为
动画参照；平地移动不接受点击的垂直坐标。

## 验收

以一个代表性浏览器动作旅程覆盖：行走并转向、途中换装、坐下与站起、
上下楼梯、爬梯、操作、交流、进食、正负反馈、动物及主脑表现。
截取实际动作不同时间点，确认关节与姿态确实变化，而非只改变动作名称。
同时检查脚底锚点、动作结束状态、读档和跨层后的旧动作清理。

纯采样测试验证关键姿态和动作端点；状态测试验证成功事件接线和动作中断。
沿用既有测试文件，不建立逐角色、逐关卡、逐动作的重复测试矩阵。

## 交付

默认试玩交付为 Windows x64 安装程序（NSIS `.exe`），包内包含正式素材、
关卡与本地 Rust 核心。运行游戏不依赖开发机的 MCP 服务。
Windows 安装、启动、进入关卡和卸载单独验收，动画以实际游戏操作验收。
