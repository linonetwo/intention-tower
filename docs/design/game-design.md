# 实验犬的意义之塔：游戏策划

本文规定游戏体验、玩法与关卡目标。实施任务见 `docs/todo.md`，完成结果和验证证据见 `docs/worklog/`。原始构想见 `wiki/tiddlers/`。

## 定位与体验

《实验犬的意义之塔》是一款围绕认知、动机和行动展开的横卷轴游戏。玩家观察角色如何将感知、需求、记忆和行动连接成有意义的结构，再通过环境、交流和有限干预改变其选择。实验犬既是经典条件反射的起点，也提示玩家：观察者自己同样可能被意义和奖励塑造。

三项支柱是认知操控（理解并改变行为逻辑）、涌现叙事（同一干预因角色与环境不同产生连锁后果）与伦理选择（效率、控制、伤害与主体性之间的张力）。操作的代价通过角色选择、关系和生活处境呈现。认知科学概念转化为玩家可观察、可干预、可验证的游戏机制。

## 玩家循环

进入场景并阅读角色、空间与目标；观察需求、行为和思维图谱，提出因果假设；在有限操作中选择行动与对象；推进时间，观察角色是否真的感知、学习和行动，以及环境和他人如何变化；比较结果与预期，调整或停止干预；检查实际行为与持续状态，完成关卡或从失败中重新尝试。玩家可以暂停、查看与调整，不要求持续快速操作。

可用选项由角色、场景、可触及对象和当前认知决定，深层记忆或条件可能暂不可用。操作包括观察、移动、交流、使用物件、训练或场景特定的认知干预；底层节点增删不直接暴露给玩家。拒绝或无效操作要有可理解反馈，不能计作成功。通关依据是指定角色实际发生的行为、世界变化及必要的持续状态；历史里程碑与最终状态分开检查，不能靠反复按按钮或先满足后破坏取胜。

## 认知与反馈

角色从环境和自身状态中形成观察、需求、动机与可选行动。注意力有限，较强或紧迫的内容竞争资源；信息洪流或污染可能挤占其他活动。学习依据体验与预期之间的差异调整关联：刺激与结果反复共现可以强化联系，不共现或反例可以削弱、区分联系；多巴胺在模型中用于表达奖励和学习信号，并非简单的快乐值。个体需求、来源、时序和情境影响学习，不保证每次干预都有相同结果。

可见思维图谱让玩家追踪概念、动机、行动及其关系变化，结合角色动作和事件反馈理解因果。视觉参考 Neo4j 的圆形节点、明确关系方向与稳定布局；编辑参考 Palantir 的对象属性、关联探索和上下文操作。节点选中、来源、联结强度与预测误差要清晰可辨。通关反馈同时展示图谱变化和实际行为结果。渲染架构见 `docs/architecture.md`。

## 空间、角色与操作

场景是明亮、可读的横向卷轴空间，参考 Latale／MapleStory 的亲切感与约四头身比例。房间、楼层、楼梯、梯子和物件与叙事、可达路径及热点一致；复杂场景可由连续房间组成。镜头跟随探索，不改变世界位置或行为结果。角色跨房间、动作和换装保持身份与比例一致，动物和非人形角色保留符合身体结构的表现。动作目录及触发契约见 [动画策划](animation.md)。

界面应像游戏而非工作软件：角色、场景、状态、可用操作和图谱相互关联。手机以触摸选择角色、对象、移动与少量上下文操作，保证热点、文字和关闭入口可触及；长地图、楼层、图谱及面板适应不同屏幕，不依赖键盘或精细指针。桌面和手机共享规则，视觉简化不能改变结果。

## 关卡设计

按体验主题归组，并非严格解锁顺序。每行是设计意图，具体完成状态另查工作日志。

| 组别 | 关卡 | 核心机制与可观察结果 |
|---|---|---|
| 动物与学习 | 巴甫洛夫的狗 | 节拍与食物配对形成条件反射；狗在强化节拍下分泌唾液，并与未强化节拍区分。 |
| 动物与学习 | 雏鹅的印刻行为 | 关键期接触形成对象关联；雏鹅自主跟随印刻对象并保持倾向。 |
| 动物与学习 | 聪明猫 | 将具体需求、按钮和相应反馈关联；猫需要时主动使用合适按钮。 |
| 虚拟与现实 | 网瘾少年 | 虚拟奖励与现实需求竞争；角色选择现实行动，并在游戏诱因重现后表现稳定变化。 |
| 虚拟与现实 | 触发网瘾 | 虚拟诱因占据对手注意力；对象实际沉浸、失去战斗能力，现实身体承受后果。 |
| 虚拟与现实 | 幻境挣扎 | 美好幻境遮蔽记忆与危险；角色真实脱困并恢复现实危险感知。 |
| 虚拟与现实 | 赛博梦中梦 | 多层虚拟成就与现实意义竞争；角色比较经历，自主选择并落实现实行动及后果。 |
| 信念与群体 | 水是有毒的 | 信念与生理需求冲突；角色实际拒水或克服恐惧饮水，补水效果以真实饮用为准。 |
| 信念与群体 | 浪潮实验 | 纪律、集体力量和归属强化身份；学生实际服从与排斥外人，蒂姆在外部命令撤除后仍可能自主维持群体。 |
| 信念与群体 | 等死死国可乎（陈胜起义） | 比较顺从与反抗的风险；指定士兵基于处境实际反抗。 |
| 信念与群体 | 死要面子活受罪 | 地位和认可与生存需求冲突；正确对象为保全面子采取有生存风险的行动。 |
| 信念与群体 | 意识形态 | 可信观察与既有信念冲突；指定受众的变化反映在实际选择中。 |
| 经济与意义 | 人从众 | 广告塑造需求，生产与供给回应需求；市民自主购买，真实交易形成利润，不靠自买或强制成交。 |
| 经济与意义 | 消费主义魔法 | 广告与品牌认同连接需求；商品形成库存，角色跨时间维持需求并实际消费。 |
| 经济与意义 | 后现代解构流浪 | 原有意义被解构，野外匮乏带来救助和互助；角色参与劳动并重建意义。 |
| 认知与恢复 | 崩溃 | 外部成果支撑的动机链遭遇挫折；角色行动崩溃，建立学习本身的意义后在不佳反馈下恢复行动。 |
| 认知与恢复 | 克苏鲁神话 | 阅读造成认知洪流并占据注意力；角色实际阅读，停止暴露后恢复调查能力。 |
| 认知与恢复 | 逆模因部 | 离开区域后记忆衰退、地点变化；角色借助记忆药和主动记忆识别地点并继续探索。 |
| 系统与冲突 | 毁灭虫族主脑 | 处理感染、敌对与控制链；电站存续，指定敌人停战，感染受控且主脑失去控制能力。 |
| 系统与冲突 | 集群意识 | 资源紧张使合作协议失效；协作真实破裂，需求缓解后存活成员恢复合作。 |
| 系统与冲突 | 模因和魔法 | 普通模因依靠关联整合，魔法模因可突破普通约束；通过真实载体传播并产生行为或世界变化。 |

## 交付与验收方向

首要试玩交付是 Windows x64 安装包：在目标设备上验收安装、离线启动、进入关卡和卸载，不依赖开发机服务。后续验收移动设备输入、长场景与性能，以及发行所需材料。规则、界面与真实浏览器旅程各自验证对应行为；动作需检查实际姿态和结果，不能只检查动作名称。
