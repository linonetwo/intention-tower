## 本批改动与试玩建议

无效命令不再增加任务次数或消耗资源。排队与执行成功分开，失败原因中英本地化；
复合命令遇到非法交易、资源不足等硬失败时整体回滚。

意识形态关选讲述者与怀疑者，先点击“强化信仰”并步进，会看到“命令没有可应用的效果”，
进度不增加。先“宣讲”并步进后，图谱才建立信仰与行动的联结，再强化会产生实际变化。
两名不同受众需要分别强化，不能反复点击同一条满值联结凑次数。

浪潮的手势教学现在实际建立纪律与服从行动的联结，教学前强化会拒绝。
这仍是行为链的前置修复，不代表已经完成自主服从、外人排斥及群体依附的完整 Wiki 设计。
