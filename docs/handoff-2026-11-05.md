## 实现约定

Rust 保持世界规则、坐标和动作结果的权威。前端 `acceptWorld` 将新快照及本次事件
转换成每名角色的当前短期动作；动作不写入存档。纸娃娃使用同一骨架和关节采样，
换装只替换部件。动物使用既有正式素材适配相同动作语义。

移动插值使用世界坐标，镜头只负责投影。重复移动接续当前显示位置及步态；
读档和跨梦境层清除旧动作。自主动作区分选择执行事件与先天反射激活事件。

## 构建与验证约定

日常构建测试在本地执行。Windows 首先使用 Linux 交叉编译；用户已授权本次必要时
使用一次 GitHub CI。后续自托管 Runner 采用 Linux 交叉编译路径。
保留机器原有缓存位置，SDK、构建中间物和临时测试工具不要放入仓库。

测试职责：Rust 验证规则，UI 验证采样和状态接线，已有浏览器旅程验证真实操作与画面。
每个 PR 最多两轮交叉审阅，修复具体问题后合并，不建立重复测试矩阵。
